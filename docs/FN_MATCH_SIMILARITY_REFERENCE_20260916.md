## 3. 使用说明

- Top1/Top2 只用于找“最值得先看源码/ASM 结构”的模板，不是最终匹配候选。
- 相似度超过 80% 的函数建议直接参考已匹配函数的控制流和声明序。

- 完成匹配后重跑本脚本，对应函数会自动从 `nonmatchings` 移出并消失。
