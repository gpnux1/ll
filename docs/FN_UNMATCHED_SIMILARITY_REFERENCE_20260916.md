## 3. 使用说明

- 同族函数适合一次性认领“明确的同构族”（AGENTS.md §2.2），先匹配族内最简单的一个，
  其余复用其结构建模（循环形态、状态机、声明序、home/register 习惯）。
- 族是按阈值边聚类得到的，成员间未必两两高度相似（存在传递性），以 Top N 矩阵为准。
- 相似度只作建模参考，不能替代逐函数字节 diff（fndiff/bytecmp/fncheck）。
- 完成匹配后重跑本脚本与 gen_fn_similarity.py，对应函数会从 nonmatchings 移出。
