## 改动 2: 裸地址符号化 (extern)

原先 `0x03000690` / `0x030006F0` 以裸地址 + 强转书写。现按项目既有模式
（同 `gUnk_03000318`）接入链接期符号：

`linker.ld`（IWRAM SECTIONS 内，按地址序插入）:
```
. = 0x00000690; gUnk_03000690 = .;   /* 待选池链表头 (UnkNode 哨兵, ListNode_Init) */
. = 0x000006F0; gUnk_030006F0 = .;   /* 待选池计数 (u8, sub_801DC20++/sub_801DD04--) */
```

`include/iwram.h`:
```c
extern UnkNode gUnk_03000690;  /* 待选池链表头: UnkNode 哨兵 (key=0xFF), 遍历取 ->next */
extern u8 gUnk_030006F0;       /* 待选池计数: sub_801DC20 挂入时 ++, sub_801DD04 摘链时 -- */
```

`src/battle_obj_core.c` 调用点替换:
| 改前 | 改后 | 位置 |
|---|---|---|
| `ListNode_InsertSorted((UnkNode *)0x03000690, …)` | `ListNode_InsertSorted(&gUnk_03000690, …)` | sub_801DC20 |
| `*(u8 *)0x030006F0 += 1` | `gUnk_030006F0 += 1` | sub_801DC20 |
| `if (*(u8 *)0x030006F0) (*(u8 *)0x030006F0)--` | `if (gUnk_030006F0) gUnk_030006F0--` | sub_801DD04 |
| `(Unk_030006A0 *)((UnkNode *)0x03000690)->next` | `(Unk_030006A0 *)gUnk_03000690.next` | sub_801FF40, sub_8020AE4 |

IWRAM 段不在 ROM 镜像内，符号仅决定链接期重定位目标地址，故指令字节不变。

## 依据（本次复核）

- `sub_801DC20` 直接把 `gUnk_030006A0[i]` 强转 `UnkNode *` 传给
  `ListNode_InitKey` / `ListNode_InsertSorted` → 前 12 字节就是 UnkNode。
- `ListNode_InitKey` asm: `strb r1,[r0]` / `str r2,[r0,#4]` / `str r2,[r0,#8]`（只用 +0/+4/+8）。
- `sub_801B964`(code.s 0x0801BE10) 用 `ListNode_Init` 初始化 `0x03000690` → 是哨兵头，
  故 `sub_801FF40`/`sub_8020AE4` 取 `->next` 且循环条件为 `key <= 0xFE`（哨兵 key=0xFF）。
- 数组大小可由 `sub_80489E8(pool, buf, 0, …)` 的 mode0 只返回索引 0..4 交叉验证：
  5 × 0x10 = 0x50，正好 `0x030006A0..0x030006F0`。
