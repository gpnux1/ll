## 2. 字节匹配要点 (全部不可省)

1. **switch 须含空 `case 2: break;`** — 3 case 触发 balance_case_nodes 中点分裂,
   得到 ROM 的 `cmp1;beq / cmp1;bgt / cmp0;bne` 树形分发。
2. **case 1 必须用具名下标**: `idx = 1; if ((s16)digits[idx] == 0 && ...) digits[idx] = ...;`
   — 常量下标 `digits[1]` 会改变 IR 伪寄存器清单, 全局改变寄存器 home (arg0 的 r8 会被
   &f_C0 就地占用 → FFFF 无家可归 → 级联 427 处差异)。permuter 25 分发现 (new_var 技巧)。
3. **OR 常量在左**: `digits[k] = 0xFFFF | digits[k];` → `mov r0, r8(FFFF); orrs r0, r1(digit)`。
4. `u16 digits[3]` + 所有读用 `(s16)` 视图 (RMW=ldrh/orrs, 比较=ldrsh, 0xFFFF 走池)。
5. `u16 i` 循环 `i <= 2` (锁存 cmp#2;bls, 截断 lsls#16/lsrs#16)。
6. `DmaCopy32(3, src, dst, 32); DmaWait(3);` ×4 (kind==0) / ×4 (kind!=0)。
7. 尾部三次独立 `gUnk_03000670[gUnk_0300068C].field_X = ...` (全局重读, 不能提局部指针);
   field_0 存 dmgAmount 原始值 (重读内存)。
8. 参数原型 `(BattleObj *, u8)` — u8 参数产生入口 `lsls r1, r1, #24`。
