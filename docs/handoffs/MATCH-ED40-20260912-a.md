## D. 与 ROM 字节一致的关键形态 (全部经 bytecmp 实证)

1. **color 未初始化 RMW**: 源码级 UB 是必要形态。三连 `(color & 0xFFFFFF00)|0x1F` /
   `&0xFFFF00FF|0x1F00` / `&0xFF00FFFF|0x1F0000` (写成一条 `(color & 0xFF000000)|0x1F1F1F`
   会丢中间 ands, 与目标不符)。调用方不压栈第三参 ⇒ 高 8 位是栈残留 (消费端不用, 无害)。
2. **外层分支用 `<=` 正向写** (`if (slot<=0xA) A; else if (slot<=0x70) B; else C;`)
   ⇒ bhi 早退 + A/B 内联、C 尾部。用 `>` 反写会把 A 挤到函数尾。
3. **B 内选择用 if/else 不用三目**: `if (f_AB==4) v=gUnk; else v=palSlot;` ⇒ bne 出跳
   (与目标一致); 三目 `?:` 会生成 beq 出跳 + 反序。
4. **返回值类型 u8 + `(s8)ret >= 0` 测试**: u8 赋值产生 lsls/lsrs 截断 (r1), (s8)>=0
   复用 lsls 中间值做 cmp/bge (无 asrs)。s32 返回类型会少 lsrs。
5. **kindFlags |= 0x8000 必须写命名中间变量**: `flags = 0x8000 | obj->headA.kindFlags;
   obj->headA.kindFlags = flags;` ⇒ 目标的 `ldrh r1 / movs r2,#0x80 / lsls r2,#8 /
   adds r0,r2,#0 / orrs r0,r1 / strh r0` (ORR 结果独立 home, 常量经拷贝进累加器)。
   直接 `|= 0x8000` 或 `= 0x8000 | x` 都是 ldrh r0 在前 + 常量拷贝进 r1, 差 2B。
   (未匹配 sub_804B654 的 u8 返回声明 + 无原型调用链是前提; `s32 sub_804B654();` 保持 K&R 无原型。)
6. 结构体成员访问 (headA.palSlot/kindFlags/f_2F, obj->slot/f_AB) 与 u8* 字节访问字节级等价。
