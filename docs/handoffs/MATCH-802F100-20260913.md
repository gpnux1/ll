## 2. 功能语义

与 sub_802C714 同族模板,但状态编号整体后移 (0 起手直接进 0x1c),演出段有差异:

- case 0: 记录位置/调色板,arg4=1 的 `sub_801CE80(obj,5,0x1B4,0xD,1)`,
  f_B6=2, state=0x1c (C714 为 0x12)。
- case 28: headA.frameIdx>0xA9 → `kindFlags|=0x100`,
  `sub_8020CC4(obj,(u8)(posX+4),(u8)(posY-0x10),0x27C,0xA,0x317,4)` → 0x1d。
- case 29: headB.kindFlags&0x800 等待 → Sfx(0x59) → headA.kindFlags&=0xFEFF → 0x1e。
- case 30: headB.frameIdx==0xC8 时 Sfx(0x5A);headB&0x1000 清 0xEFFF + state&=0xDFFF;
  headA&0x1000 → state&=0xDFFF + `sub_801CE80(obj,0,g822,g824,0)` → 0x1f。
- case 31: headA.kindFlags&0x800 等待 → 0x15。
- case 21: `sub_8020CC4(obj,0x82,0x7D,0x1B4,0xA,0x313,5)`;headB.f_2A=0 → 0x16。
- case 22: headB&0x800 等待 → Sfx(0x4E,1,1) → 0x17。
- case 23: headB.frameIdx>0x18 → `sub_804BF14(0,3,0x10,0x1C,0x1F,4,4,-1,2)`;
  计数=0;sub_8044514(0x32) → 0x18。
- case 24: 计数>3 → 0x19 + sub_804C728(0,3,0x10);否则计数++。
- case 25: headB.frameIdx==0x5B → Sfx_StopTrack(1);headB&0x1000 → state&=0xDFFF, state=9;
  计数++ (与 case24 共享尾块)。
- case 9: 三个全局 ==0 → result=1。

## 3. 关键形状
