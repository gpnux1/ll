# MATCH-804BDD8 — OBJ 调色板淡变槽 setter

- **current_name**: `sub_804BDD8` (status=1, byte 匹配)

- **推理依据**: E0 (ROM 字节) + E1 (ASM) + E2 (调用者用例 + 同族 sub_804B834/BD54/B8E8)

## 语义
建立 OBJ 调色板淡变槽 `[arg0, arg0+arg1)`:
对每个非空槽 (`ctrl & 0xF != 2`, 即非"进行中"), 先 `sub_804C638(slot)` 备份当前 OBJ
调色板到镜像, 然后装配一个 opcode=2 的淡变条目:
- `ctrl = 0x22` (opcode 2 + 0x20 禁止颜色重置)
- `palSlot = 槽号 (arg0 + i)`
- `period = arg2`
- `counter = 0`
- `span = (arg4 << 4) | (|(s8)arg3| & 0xF)` (高半 = 帧数, 低半 = 宽度)
- `frameIdx = 0`
- `dir = arg3 >> 7` (arg3 为带符号方向, 负数取绝对值放低 4 位)

返回 **BG** 调色板表 (`gBgPalAnim`) 同槽的 `palSlot` (`s8`), 供调用者作为目标槽使用。
注意: 写入用 **OBJ** 表 (`gObjPalAnim`), 返回读 **BG** 表 (`gBgPalAnim`) — ROM 事实, 非笔误。

## 机器契约
- **args**: `r0..r4 = arg0..arg4`, 均 u8 (`lsls/lsrs #0x18` 逐参截断)
- **return**: `r0` = `(s8)gBgPalAnim[arg0].palSlot`, 尾部 `lsls #0x18; asrs #0x18`
- **callees**: `sub_804C638(u8)` (DMA 备份 OBJ 调色板槽)
- **indirect_tables**: 无
- **memory_reads**: `gObjPalAnim[arg0+i].ctrl` (0x03000BE8), `gBgPalAnim[arg0].palSlot` (0x03000AE8)
- **memory_writes**: `gObjPalAnim[arg0+i].{ctrl,palSlot,period,counter,span,frameIdx,dir}` (16B 项)
- **persistent_state**: 调色板动画表, 跨帧由 `sub_804C6B0` 等逐帧消费
- **script_relation**: 被脚本驱动的演出状态机 (`sub_80285A0` 族) 间接调用, 本函数本身不读写脚本状态

## 关键 GCC2.9 形状 (破解点)
目标 `0x4a..0x50`:
```
movs r1, #0xf
ands r0, r1        ; r0 = |(s8)arg3| & 0xF  (mask 就地复用 abs 的 home r0)
lsls r7, r4, #4    ; r7 = arg4 << 4         (comb 的目标寄存器)
orrs r7, r0
```
`span` 的低 4 位掩码必须先算成一个 **u32 临时** `m`:
```c
m = abs & 0xF;
entry->span = (arg4 << 4) | m;
```
若写成行内 `entry->span = (abs & 0xF) | (arg4 << 4);`, GCC 会把 AND 折进 `span`
的目标寄存器 (r7) → `ands r7, r0; lsls r0, r4, #4` → 差 3 字节 (base.c 旧最优)。

附加约束:
- `m` 类型必须 `u32`/`u16`/`int`; `u8` 会改变寄存器分配 → 差 11 字节。
- 循环用 `do-while` 展开 + `base = (u32)gObjPalAnim` 先于循环, 与同族
  `sub_804BB64`/`sub_804BE90` 一致。
- 结构体更新后 `entry = (PaletteAnimEntry *)(idx * 16 + base)` (保留 `idx*16+base`
  的裸算术, 不要用 `&gObjPalAnim[arg0+i]` —— 后者会改变地址计算指令) 仍 184B 精确匹配。
