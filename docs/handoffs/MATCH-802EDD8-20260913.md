## 关键 GCC2.9 形状
- case0 的 `f_B6=2`/`f_B4=0` 写顺序: `adds r2,r4,#0xB6; strh` 后 `adds r0,r4,#0xB4; strh` —
  源码按 `f_B6` 先于 `f_B4` 写即自然生成。
- case24 的 `state=9` 之后**必须**仍走共享 `gUnk_03000825 += 1` 尾块 (asm `b _0802F0E4`),
  即 `if (...) { ... state=9; } gUnk_03000825 += 1;` (不在 if 内 break)。
- case9 的计数自增与 `result=1` 共享尾块: 写成 `if (全0) result=1; else 计数+=1;` —
  asm 里 3 个 `bne _0802F0E4` 与 `movs r5,#1; b tail` 直接对应。
- case28 的 `(u8)(posX+4)` / `(u8)(posY-0x10)` 必须显式截断 (asm 有 `lsls/lsrs #24`)。
- case0 读 `headA.f_1E`(u16)/`headA.palSlot`(u8) 而非 raw `obj[0x2A]/[0x35]` (同 sub_802E6C8)。
