  2. 若直接替换为 `obj->fxKind = 1; else obj->fxKind = 0; obj->animSubIdx = 0;`，GCC 2.9 会触发公共子表达式消除 (CSE)，在 `fxKind` 赋值后提前将常量 0 存入被调用者保存寄存器 `r5`（并导致 `count` 移入 `r6`，函数 prologue 变为 `push {r4, r5, r6, lr}`），使得函数体由 168 字节缩水至 164 字节，导致全局出现 4 字节位移偏差。
- **攻破机制**:
  1. 遵照同族兄弟函数 `sub_804DB64`、`sub_804DC24`、`sub_804DCD8` 的标准习语：
     ```c
     if (Rng_LcgNext() % 0x65 <= 0x45)
     {
         flag = &obj->fxKind;
         *flag = 1;
     }
     else
     {
         flag = &obj->fxKind;
         *flag = 0;
     }
     *flag = 1;
     ```
     在 `if/else` 双分支内部赋指针 `flag = &obj->fxKind;`，阻断了 GCC 跨基本块提前物化常量 0，自然生成 ROM 目标指令流：
