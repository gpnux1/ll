## 关键形状点 (GCC2.9) — 本轮突破
**0x261 块必须用"独立临时收载入值, 再与常量变量相与"**:
```c
x  = gGstate324;   /* 载入值 → r0 */
v2 = 0x261;        /* 常量    → r1 (v2 = s8 参数副本的 home) */
v2 = x & v2;       /* ands r1, r0; 结果留 r1 */
gGstate324 = v2 | 8;
```
- 目标形态: `ldrh r0,[r4]; ldr r1,[pc]; ands r1,r0; movs r0,#8; orrs r1,r0; strh r1,[r4]`
  —— 值入 **r0**, 常量入 **r1**, ands 目标 = r1。
- 之前所有写法 (含 base.c) 把值载入 v2 的 home (r1)、常量入 r0, 于是 `ldrh r1`/`ldr r0` 镜像互换。
- 决定性因素: 让 `v2` 的**最后一次定值来自常量**, 且 AND 结果**回写 v2**; GCC2.9 于是把
  常量放 v2 的 home (r1) 并让 ands 以 r1 为目标。
- 只改这一处因素即从 DIFF=2 → **DIFF=0**; 其余 200 字节完全相同。

### 已排除 (每个只改一个因素, 均停在 2 条差异)
- 操作数顺序 `(0x261 & v2)` / `8 | (v2 & 0x261)`; 类型 `(u16)/(int)/0x261u/(u16)` 强转
- 独立掩码变量 `u16 m = 0x261;` 的声明/赋值先后; `v2 = 0x261; gGstate324=(v2&x)|8;`
- 双变量 `t=gGstate324; v2=(t&0x261)|8;` → 8 条 (ands 目标也翻转)
- `int x = gGstate324;` → 15 条 (load 对上但常量落 r2 并多 `adds r1,r2`)
- 拆写 `&= 0x261; |= 8;` / 就地 `v2 &= …; v2 |= …;` → 12 条; 去 v2 直接 RMW → 94 条
- permuter (tools/decomp-permuter, 12 核, ~39000 iter) 未突破 base 35 — 分数不迁移, 以 bytecmp 为准

## gGstate324 结构性质 (附带结论)
**已验证事实**: 地址 `0x03000324` 在全部 30+ 访问点一律 `ldrh/strh` 整字 u16 + 立即数掩码。
专用 API (sio_link.c:578-592, 均已匹配): `sub_80187B4()` 整字读; `sub_80187C0(u16)` 运行期掩码 OR 置位;
`sub_80187D4(u16)` 运行期掩码 BICS 清位。实际调用 `sub_80187C0(0x400)` ×3,
`sub_80187D4(0x10)/(0x1000)`, `sub_80187B4() & {0x20,0x200,0x220,0x40,0x400,0x1000,0x4000}`。
地址被取 (`sub_804B224(&gGstate324)`), 整字传参 (`sub_804B080(obj,state,gGstate324)`)。

**位语义 (强推断)**: bit0=重入请求, bit3=对象冻结, bit4=暂停图块 DMA, bit5/bit9=战斗分级,
bit6=脚本相关, bit10=等 DMA 完成, bit11=BG 图块待装载, bit12=跳过段0/重排, bit14=放宽形态限制。
未发现 0x325/326/327 任何访问 → 该字独立, 不隶属跨这些字节的结构体。

**为什么不是位域**:
1. 运行期掩码 API 是决定性反证 —— 位域无法表达 `w |= runtime_mask` (调用点传 0x400/0x10/0x1000,
   心智模型是 bit 掩码而非字段)。
2. 多 bit 组合测试 `& 0x220` / `& 0x261` 非单字段读取。
3. 整字传值/取址。
4. **实测反证**: 同一编译链下, 平铺 u16+立即数掩码 = 2 条差异; union{位域;u16 raw} 全用 `.raw` = 18 条;
   纯位域成员访问 = 81 条 (寻址/宽度/流程全变)。原 ROM 用的是平铺 u16。
