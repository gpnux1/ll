## 语义

opcode3 是"淡变"动画: 每帧把 period 折成插值移位量 `shift` (对 period 连续右移, 每步 +1,
上限 7), 再调 `sub_804B56C` 从镜像缓冲 (dest) 取 16 色, 用 entry 的 dR/dG/dB 按
`weight = period - counter` 与 `shift` 插值写入当前调色板 (src)。随后推进 counter:

- `ctrl bit6 (0x40)==0`: 单向递减 counter, 减到 `period - dir` 为止;
- `ctrl bit6==1`: 递增 counter, 到 `period` 后按目标缓冲结束该槽淡变
  (BG 镜像 0x02036AC0 → `sub_804BB64`; OBJ 镜像 0x02036CC0 → `sub_804C10C`)。

## 关键形状突破 (GCC2.9 / agbcc)

shift 折叠循环的目标形状是**顶测 while 被 `expand_end_loop` (stmt.c) 滚到循环尾**的形态:
前置一条无条件 `b` 跳到循环尾的测试, 循环体在前:

```c
entry->shift = 0;
if ((v >>= 1) != 0)
{
    do
    {
        if (++entry->shift > 7)
            break;
    } while ((v >>= 1) != 0);
}
```

- 必须先把 `entry->period` 缓存进**局部 `u8 v`**。直接对 `entry->period` 做 `>>=` 会重读内存
  (425 差), 不缓存 `v` 则前置 `b` 消失 (205 → 正好差 2 字节)。
- 姊妹 `sub_804B3C0` (@0x0804B3C0) 的 shift 循环是同一 idiom, 可交叉验证
  (`cmp r1,#0; beq done` + `lsrs; bne` 的滚动结构)。
- 反面教材 (均为非滚动 while, 差 2~5 字节): `while ((v>>=1)!=0) { if(++shift>7) break; }`
  只差前置 `b`; 纯 `do{}while` 缺前置 `b`; `for(;;)`+break 同。
