# HANDOFF: 0x03000DDE–0x03000E30 重命名 (物件演出/多对象演出/战后掉落)

- 日期: 2026-09-14, agent: zcode
- 前置分析: 同日本目录 ANALYSIS 结论 (三子系统), 本文档记录重命名实施与 E3 新证据。
- 结果: **12 个 IWRAM 符号重命名 (含 4 个新登记) + 11 个函数全链改名**。
  全量 `make` + `sha1sum -c ll.sha1` OK (869/1059), 11 函数 fncheck OK。

## 1. E3 新证据 (本次改名期间取得, 修正前报告)

- **gItemNames (0x08095028, 256 项 × 8B, 游戏自定义 charmap) 解码**:
  - ids 0x19–0x31 = **武器攻击道具** (アイスハンマー/ソニックハンマー/フレイムロッド/
    アクアスタッフ/メテオロッド 等)。ItemUseFx_RunWeapon (原 sub_804E2AC) 的 25 项跳表中
    仅 8 个 id 有 dmgAmount 预设 (0xA7..0xAD 与 2), こううんの杖(0x2C) 不在预设之列。
  - ids 0xDD–0xE4 = **回复/辅助消耗品** (ヒールガム/ヒールドロップ/メンタルガム/
    エンジェルティア/パラクリーン/ポイズンクリーン/プレアウォーター)。
    ItemUseFx_RunConsumable (原 sub_804E0E4) 服务于此段。
- **掉落 LUT add 值即道具 id**: 221=ヒールガム, 222=ヒールドロップ, 227=ポイズンクリーン
  —— 敌人掉落物即消耗品 ✓。
- **+15 升档 = 升稀有档**: 0xDD(ヒールガム)→0xEC(ドラゴンリング), 0xDE→0xED(竜のダイヤ),
  0xE3(ポイズンクリーン)→0xF2(ドロボウのこころ), 0xE1→0xF0(アルテナオーブ)。
  幸运系装备 (效果字段5==4, 经 sub_804DD90 位域表判定) 使掉落映射进稀有品段。
- **修正前报告两处**: ① 0x19–0x31 不是"回复药"而是武器攻击道具; ② 死代码 BattleDrops_Clear
  的记录布局与 BattleDrops_Roll 一致 ({itemId@+0, count@+1}), 旧 typedef 成员名 "field_2"
  实际位于 +1 (两 u8 连排), 之前的"不一致"判断是成员名误导。
