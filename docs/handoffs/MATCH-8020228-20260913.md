## 2. 字节匹配要点 (三条不可省)

1. **两条路径都清 5 个 statMods**[0..4] (0x7E..0x86)。表路径在 noa 之后清,clear 路径在
   调 sub_802031C 之前清。数成 4 个会少 4 条 strh (差 8 字节)。
2. **lv 的和值必须用具名 int 临时承接**:
   ```c
   ret = sub_8047FCC((u8)sub_80187A8());
   sum = ret + arg1->lv;
   arg1->lv = sum;
   ```
   任何直接写法 (`lv += f(...)`、`lv = f(...) + lv`、`lv = lv + f(...)`) 在真实 TU 里都会把
   加法结果绑到 r1 (`adds r1, r1, r0`) 而非目标的 r0 (`adds r0, r0, r1`), 差 2 字节。
   这是 permuter 10 分候选发现的 (new_var 技巧), 真实 TU 判定下确认字节全等。
   机理: 具名临时多出一个 int 伪寄存器, 改变 local-alloc 对加法 dest 的绑定顺序。
3. `slot <= 0x70` 用无符号比较 (`cmp #0x70; bls/bhi`); u8 参数入口 `lsls r2,#24; lsrs r6,r2,#24`。
