## 3. 本轮新增的定量结论（这是交付重点）

取数方法：`agbcc -dg` → `x.pp.greg`；脚本留在 `.scratch/gpnux-ab40/greg.sh` 与 `scan.py`
（后者自动抽取"入口 home 序 / 存储序 / 字节差"，一并把 `mov r7, sb` 之类的序言干扰排除掉）。

### 判据 A — 硬寄存器取用顺序

`find_reg()` 实测顺序

```text
O = r0, r1, r2, r3, r4, r5, r6, r7, ip(r12), r8, r9      (r10/r11 不可用)
```

**ip 排在 r8/r9 之前**（这点此前没人写下来，是理解"为什么 A 拿到 ip 而不是 r8"的关键）。
校准法：造一个 4 个候选 `live_length` 全等的写法（平铺 `A=0;B=0;C=0;D=0;`），
此时全平手、按 regno 升序发号，实测 `A=r7, B=ip, C=r8, D=r9`，直接读出 O 的 4 个空位次序。

### 判据 B — live_length 闭式

对 n 条 `gX = 0;`，**精确成立**（σ=δ=2 由 3 个独立候选的 4 元一次方程组解出，不是拟合）：

```text
LL(X) = K + 2 * ( e(X) − c(X) )
c(X) = 符号在源码中【首次出现】的序号   = 池加载顺序 = asm 里 4 条 ldr 的顺序
e(X) = 该地址【最后一次】存储的出现序   = asm 里 4 条 strb 的顺序
       （链式赋值 X=(Y=0) 先算内层 Y，故 e(Y) < e(X)）
分配序 = (e−c) 升序，平手按 c（＝regno）升序
```

验证数据（全部吻合）：`plain / A;B=(C=0);D / D;A;B=(C=0) / A;D=(C=(B=0)) / A;B;D=(C=0) /
D=(C=(B=(A=0))) / A=(B=(C=(D=0))) / (A=(B=0));(C=(D=0)) / D;C;B;A / D;A=(B=(C=0)) / …` 共 20+ 个。

### 判据 C — 不可达性证明

目标要求 分配序 `C, D, A, B`（因为 homes 是 `C=r7(1st), D=ip(2nd), A=r8(3rd), B=sb(4th)`），
而 asm 里存储序是 `A,B,C,D` → `e = A0,B1,C2,D3`。

```text
需 (e−c)(C) < (e−c)(D) < (e−c)(A) < (e−c)(B)
即 2−c_C < 3−c_D < 0−c_A < 1−c_B
中间那步要求 c_D − c_A > 3，但 c 只能取 0..3  → 矛盾。
```

**推论：任何"4 条 `gX = 0;` 赋值语句"的写法（含全部排列、链式、重复）都不可能命中。**
（若 e 序 = c 序，则所有 `(e−c)=0`，分配序恒等于源码序，更不可能。）

### 已穷尽（与模型 100% 吻合，无一例外）

- `4^4 + 4^5 + 4^6 = 240 + 1560` 个**含重复**的语句序列（重复写 `…; B=0; …; B=0;` 会被编译器
  删掉**前一次**存储只留最后一次，从而把 e 序与 c 序解耦 —— 这是唯一能改变 `(e−c)` 的合法杠杆）。
  实测 homes 与模型预测逐条一致，无一个同时满足 `STORE-OK` 与 `HOME-OK`。
  重复语句**不会**产生第 5 个地址伪寄存器（`-dg` 里始终只有 4 个 `refs=2` 的 pointer allocno）。
- 无效杠杆：裸地址 `*(u8*)0x…=0`、数组 `gX[0]=0`、结构体成员 `.v=0`、`*&gX=0`、
  `volatile` 逐个/全量组合、`D = C` 读传播（**与 `D=0` 逐字节相同，且不给 C 加 ref**，
  再次确认经验 117 的 refs 杠杆在此失效）、死语句插入（`i=i`/`count=count`/`(void)0`/`if(arg0==0xFF){}`）、
  extern 声明顺序、逗号表达式、临时零变量 `z`。

### ⚠ 14 B 的"近解"是伪造语句，禁止合入

`A=0; B=0; C=0; D=0; B=0;`（末尾冗余重复一次 B）能拿到 **完全正确的 home 序**
`A=r8, B=sb, C=r7, D=ip`，bytecmp **14 B**，但存储序被拖成 `A,C,D,B`。
语义冗余、靠假语句制造 `(e−c)`，属铁律 4 禁项（同经验 117 的 `dirMask++; dirMask--;`），
**不得合入**。它的唯一价值是证明：目标 RTL 里 B 的地址伪寄存器"最后使用位置"确实晚于 D。

## 4. 剩余唯一可能的方向（未走）

模型成立的前提是 `σ = δ`（地址定义 RTL 间隔 = 存储 RTL 间隔，均为 2）**且 4 条存储同属一个基本块**。
要破必须改 **RTL 形状 / 基本块结构**：

1. **基本块结构确实是活杠杆（已实测）**：把 4 条赋值包进 `do { … } while (0);` 或
   `for (;;) { …; break; }`，分配结果从 `A=r7,B=ip,C=r8,D=r9` 变成 `A=r6,B=r7,C=ip,D=r8`
   （bytecmp 56 B，代码已被循环结构带坏，但证明 σ/δ 与分块**可以**被 C 结构改变）。
   `if (1) { … }` / `switch (0) { default: … }` 则完全无变化（28 B，与平铺同）。
   → 下一步应找**不引入额外指令、只改变分块**的写法（注意 `goto` 属铁律 4 禁项）。
2. 让 `σ ≠ δ`（例如让 B→C 的地址定义之间多出 ≥3 个 insn 空位，而存储之间不变）；
3. 或存在**第 5 个地址伪寄存器**（使 c 的取值范围超过 0..3）。
下手点：`agbcc -df` / `-dc` 转储确认 4 条 def 是否真的等距 2 空位；
或先拿已匹配的同构姊妹 `sub_804ACC0`（`src/battle_engine.c:2432`，表 0x0839B462，无高位寄存器）做反例对照。
变体在 `.scratch/gpnux-ab40/v6/`（`g1_dowhile0` / `g4_for1` 是分块杠杆的正面证据）。
