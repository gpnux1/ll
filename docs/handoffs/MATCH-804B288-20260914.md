1. **`fill` 必须为 `vu16` (非 volatile 会被常量折叠/寄存器重量化)**:
   声明为 `vu16 fill;` 并每次给 `fill = 0;`，使得编译器在栈帧上分配 4 字节并复用该局部变量地址传给 `REG_DMA3SAD`。
2. **DMA 块展开为局部 `vu32 *dmaRegs` 块**:
   局部块内 `vu32 *dmaRegs = (vu32 *)0x040000D4;`，保证每次 DMA 前重新加载 `0x040000D4` 进 `r1`，与目标汇编完全一致。
