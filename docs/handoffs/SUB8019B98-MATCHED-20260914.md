## 三个决定形状的 lever (本次攻坚核心)
1. **case1 表基址必须经 `tbl` 局部承接**: `tbl = gBgLoadTable; entry = &tbl[arg0];`
   否则 GCC 把池加载 `ldr =table` 调度到索引计算之后 (目标顺序: ldr =table → lsls/adds 索引 → ldrh count)。
   仅此一处即从 21 字节差降到 **0**。
2. **case3/4 的调色板值提到循环外 + 循环体带花括号**: `u16 pal = (arg2 & 0xF) << 12;` 前置语句,
   否则 GCC 在循环体内重算且用 `lsls #28/lsrs #16` 复合形态。
3. **case5 的 VRAM 目标用 `(i << 11)` 单独算**: `i = (arg1==3) ? 0xF : 0xD; dmaRegs[1] =
   ((i << 11) + 0x06000000) + (idx << 9);` —— 内联三目版本差 100+ 字节。DMA 指针须在 if 内层块中声明。
