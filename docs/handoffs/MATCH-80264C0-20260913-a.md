## 2. 语义 (已验证事实)

`switch (gUnk_03000820)`:

- **0 起手**: 暂存 `posX/posY → gUnk_03000828/29`, `gUnk_03000825=0`, `obj->headA.kindFlags &= 0xFBFF`
  (清 0x400), `sub_80444A4(obj)` (清同组 dmgAmount) → 1。
- **1 摆动**: 每帧异或 `kindFlags & 0x200`; 帧计数 `gUnk_03000825 <= 4` 时自增并插值 —
  `obj->posX = sub_801768C(gUnk_03000828, slot≤0xA ? -0xA : +0xA, 5, 帧计数, 2)`,
  `y0 = gUnk_03000829`, `delta = (arg1->posY - y0)/0xA`, `obj->posY = sub_801768C(y0, delta, 5, 帧计数, 2)`;
  超过 5 帧: 计数清零, 按 slot≤0xA 把 posX 吸附到
  `(obj->f_C3/2 + arg1->pad_C4[0]/2) + arg1->posX + 0xA` (否则镜像减), posY = arg1->posY + 1 → 2。
- **2 摆动2**: 同样的 0x200 异或与 5 帧插值, 但只插 posX, 基准为上一态吸附点 (向 ∓0xA 收),
  ∓0xA 为 5 帧delta; 超帧后若 `kindFlags & 0x200` 清 0x200 → 3。
- **3 起动画**: `gUnk_03000822 = obj->headA.f_1E`, `gUnk_03000824 = obj->headA.palSlot`;
  若 `slot <= 0xA`: `sub_801CBA4(obj,1,0x1B4,0xD,gUnk_03000826); gUnk_03000826 += 1;`
  (gUnk_03000826 是 u16, 读 u8 传参 + 读 u16 自增); 然后 `sub_801CE80(obj,1,0x1B4,0xD,0)`,
  `sub_803F5B4(obj)`, `gUnk_03000825=0` → 4。
- **4 等 DMA 起**: 若 `!(kindFlags & 0x800)` → `Sfx_Play(0x50,1,0)` → 5。
- **5 等动画完成**: 若 `kindFlags & 0x1000`: 清 0x1000, `sub_80207DC(obj, posX, posY, gUnk_03000822, gUnk_03000824)` → 6;

## 4. 剩余差异与下一步

差分 ~154 条指令 (target 1228B vs 候选 1164B, 差 64B), 全部是 GCC2.9 形状问题, 无已知语义差:

1. **case1/2 的 posX 调用被 cross-jump 合并**: 目标两个分支各保留独立的 `bl sub_801768C`
   (0xf8/0x13c); 候选被优化成共享调用点。目标两分支 setup 差异 (r2,counter ↔ r1,counter;
   r5=2 常量), GCC 未合并。候选已试: 反序 if、独立 dx/arg5 变量、delta 前置 — 均未消除合并。
2. **case3 比目标大约 0x1e 字节**: 待逐条对齐 (怀疑 `gUnk_03000826` 的 u8 读/u16 自增顺序,
   以及 `0x1B4` 常量物化)。
3. **寄存器全局分配**: 目标 obj→r6/arg1→r7/entry→r5/0x03000820→r4/result→r9/counter_addr→r8;
   候选 obj→r5/arg1→r4/entry→r6/0x03000820→r7/result→r8。目标把 `&gUnk_03000825` 放进 callee-saved
   r8 (跨 sub_801768C 存活), result 进 r9。

下一步建议:
- 先攻 case3 的 0x1e 字节, 再回来处理 case1/2 的 cross-jump 合并 (这是最大单块差)。
- permuter 已验证对本题 (base score 8290→7010 但结构不变), 不宜作为主手段; 分数改善来自
  `new_var=0xA` 之类的噪声改写。以 fndiff 逐块对齐为主。
- 姊妹函数 sub_802698C (0x0802698C, 同族, case0 会 extra `sub_803F5B4` 且 state 直接=3)
  可作对照, 但本例 case0 只有 sub_80444A4。
