## 语义结论

战斗 UI 槽位刷新 (HP/MP 数字 + 渐变量表):

1. `memcpy(tbl, gUnk_0839DF5C, 8)` — 强度斜坡 {1,2,3,4,4,3,2,1}。
2. 调色板参数三分支: `state&0x80` → `sel=palA=palB=flashLevel, flag=0`; 否则
   `sub_801D12C(obj,0)` 步进后 `palA=substate`, `palB=0`, `substate==1/2` 时
   `palB=sel=1/2`, 否则 `mp==maxMp` 时 `sel=3`; `flag=3`。
3. 三个 3 位数图块: `8018EA8(hp, x=arg1*5+5, 0x10, palA, flag)`、
   `8018EA8(mp, x, 0x11, sel, flag)`、`8018FC0(arg1, x=arg1*5+4, 0x12, palB, palA, sel, flag)`。
4. `state&2` 时生成 0x80 字节渐变 LUT 到 `0x02021040+arg1*0x80`:
   `byte(i,j,k) = ((i*8+k*2 >= 阈值) ? 0xF0 : tbl[j]<<4) + ((i*8+k*2 >= 阈值+1) ? 0xF : tbl[j])`,
   i<4, j<8, k<4; 阈值 = `*(u16*)&obj->animPtr` (animPtr 槽低半字, 0-32 量程);
   随后 `state &= ~2`。
5. 末尾 `if (state & 1) state &= ~1`。

## 匹配关键 (agbcc 形状, 供后续同族参考)

agbcc **无指令调度器** (sched.c 未编入), 指令顺序 = RTL 展开序, 因此源语句顺序即机器序:

1. `flag` 必须 **u8** (u32 会驻留寄存器, u8 才落栈 [sp+0x18] — 与目标一致)。
2. `sel` 必须 **u32** (u8 会错位到栈)。
3. `sub_8018EA8` 原型第 4 参 = **unsigned int** (非 u8) — 影响调用点截断形状。
4. LUT 字节必须经 **int 临时** (new_var) 再存 `*dst++` — 直接内联三元式寄存器家不同。
5. else 路径的 mp/maxMp 判等必须写成 **指针局部 + 分步读取**:
   `p70=&mp; p72=&maxMp; v70=*p70; sel=0; if (v70==*p72) sel=3;`
   — RTL 序 [&mp, &maxMp, load mp, sel=0, load maxMp, cmp] 与 ROM 逐条对应;
   写成 `sel=0; if (obj->mp == obj->maxMp)` 会把 sel=0 排在块首 (差 1 条指令位置)。
6. `*(u16*)&obj->animPtr` 与 u16 字段视图 `obj->f_88` 代码生成等价 (别名类同为 u16 读)。
7. 分数轨迹: 8118 (初版) → 7391 (pos int+免局部) → 5921 (flag u8) → 3271 (sel u32) →
   1933 (f_88 字段读) → 465 (免 early sel=0) → 400 (= 仅字面池伪影) — decomp-permuter
   随机模式贡献 335/65 两轮关键变换 (new_var 临时 + 8018EA8 原型 + 语句重排), 其余手工。
