## 2. 机器契约与语义建模
该函数是战斗回合异常状态结算状态机（`sub_804A368`）的辅助例程，负责按给定的异常状态位掩码（`mask`，如中毒 `0x01`、麻痹 `0x02`、睡眠 `0x04`、混乱 `0x08`、沉默 `0x10` 等）在参战角色（我方和敌方）中进行筛选，并将命中的角色槽位号依次记录到全局缓冲 `gTurnAilSlots` 中，同时重置遍历游标 `gTurnAilIdx` 与计数 `gTurnAilCount`。

### 2.1 依赖关系与生命周期
- **上游调用者**:
  - `sub_804A368`（战斗回合状态机）：按 `gTurnAilMask` 检查当前存在的状态位，依次调用 `sub_804AA2C(mask)` 收集各状态受影响角色。
- **被调子函数**:
  - `GetObjPool()`: 获取 `BattleObj` 池首地址；
  - `sub_80489E8(pool, buf, mode, flags)`: 参战角色槽号筛选器（`mode=0` 为玩家侧 0..4 槽，`mode=1` 为敌方 5..11 槽）。

### 2.2 全局变量与状态
- `gTurnAilSlots` (`0x03000988`): 异常状态角色槽号缓冲（12 字节）。
- `gTurnAilCount` (`0x03000994`): 命中的角色数量（写入前先置 0）。
- `gTurnAilIdx` (`0x03000995`): 异常状态遍历游标（清 0，供 `sub_804A368` 随后逐帧遍历）。

### 2.3 业务逻辑
1. **重置计数器与游标**:
   `gTurnAilCount = 0; gTurnAilIdx = 0;`
2. **收集参战列表**:
   `count0 = sub_80489E8(pool, buf0, 0, 0xFF);`
   `count1 = sub_80489E8(pool, buf1, 1, 0xFF);`
3. **玩家侧筛选 (Loop 1)**:
   遍历 `buf0`，若 `pool[buf0[i]].statusAil & mask`：
   `gTurnAilSlots[gTurnAilCount++] = buf0[i];`
4. **敌方侧筛选 (Loop 2)**:
   遍历 `buf1`，若 `pool[buf1[i]].statusAil & mask`：
   `gTurnAilSlots[gTurnAilCount++] = buf0[i];` （★原版 ROM 复制粘贴 bug）

## 3. 原版 ROM 复制粘贴 Bug
在 Loop 2（敌方异常状态角色槽位收集）中：
原版汇编指令为：
```arm
	mov r1, sl            @ sl = &buf1[0]
	adds r0, r1, r2
	ldrb r1, [r0]         @ r1 = buf1[i]
	movs r0, #0xc8
	muls r0, r1, r0
	adds r0, r0, r6
	adds r0, #0xb8
	ldrh r0, [r0]         @ r0 = pool[buf1[i]].statusAil
	mov r4, r8
	ands r0, r4
	cmp r0, #0
	beq _0804AAE8
	ldrb r1, [r3]         @ r1 = gTurnAilCount
	adds r1, r1, r5       @ r1 = &gTurnAilSlots[gTurnAilCount]
	mov r7, sp            @ r7 = sp (&buf0[0])
	adds r0, r7, r2
	ldrb r0, [r0]         @ r0 = buf0[i] (★此处读取了 buf0[i] 而非 buf1[i])
	strb r0, [r1]         @ gTurnAilSlots[gTurnAilCount] = buf0[i];
	ldrb r0, [r3]
	adds r0, #1
	strb r0, [r3]
```
这是原版游戏开发者在编写敌方处理分支时，从 Loop 1 复制粘贴，并在条件判断处将 `sp` 改为了 `sl`（`buf1`），但在 `then` 块向 `gTurnAilSlots` 写入槽号时，漏改了 `mov r7, sp`（仍然读取了 `buf0[i]`）。
该 bug 与同文件前序函数 `sub_804A148` 中的复制粘贴 bug（误读 `buf0[i]` 计算 `gTurnAilMask`）如出一辙，属于同一作者在编写该回合状态机模块时的连带手误。C 代码中忠实保留此行为并加注释说明。
