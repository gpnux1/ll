## 语义 (E0/E1/E2)
对象链 (`0x03000318` 行动链, UnkNode key<=0xFE 为有效节点) 上做**两趟**处理:

- **趟1 图形装载** (逐节点, 每帧最多装一个头): headA.kindFlags&0x800 (需装载) 且本帧没装过 →
  `ObjGfxLoad_Step(&headA)`; 若 `state&0x2000` (跳跃演出) 且 headB.kindFlags&0x800 且
  headA 当前不需要装载 且没装过 → `ObjGfxLoad_Step(&headB)`。跳出趟1 后 `node=node->next`
  (跳过 key>0xFE 的终止节点)。
- **趟2 动作/OAM 刷新** (每节点):
  1. `kindFlags&0xF == 3` → 直接 `headA.f_2D = state` (跳过 sub_804B080)。
  2. 否则: `state&0x40` 不置时回填 `headA.f_2B = posX`, `headA.f_2C = posY - pad_C1`;
     `state = sub_804B080(obj, state, gGstate324)`; `state&4` → `f_2D = state`, 否则
     `f_2D = state = sub_801D378(obj, state)` (OAM 条目装配, 返回槽号-1)。
  3. headA/headB 任一 `kind&0xF == 6` → `sub_801A270()` (填充 0x020362C0 tilemap 缓冲)。
  4. `(u8)(slot-12) <= 0x64` 且 `!(kindFlags&0x8000)` 且 `variantClass == 4` → 置 `kindFlags|=0x8000`,
     `f_2F = sub_8020798()` (= gUnk_03000744), 记 flag8000=1。
  5. `state = sub_801B878(&headA, state, &out)` (帧构建), `f_2E = f_2D - state`;
     若置过 0x8000 → `kindFlags &= 0x7FFF` (恢复)。
  6. `state&0x2000` 且 `!(headB.kindFlags&0x800)` → `headB.f_2D = state`,
     `state = sub_801B878(&headB, state, &out)`, `f_2E = f_2D - state`。
- 返回 0 (r9/sb 恒 0)。

## 关键形状点 (GCC2.9)
1. **node(UnkNode*) 循环变量 + obj(BattleObj*) 体变量** (sub_8018070 同族双变量):
   循环用 UnkNode* 访问 key/next, 体里 `obj = (BattleObj*)node` 产生 `adds r4, r6` 拷贝。
   单变量版本 (BattleObj* 直接 `node->node.next`) 无拷贝、寄存器分配全乱。
2. **参数直接用 UnkNode***: 原型 `u8(UnkNode*, u8)`, 首参拷贝 `adds r6, r0` 落在最前
   (r1 的 u8 截断 lsls/lsrs 在其后)。用 BattleObj* 参数 + `node=(UnkNode*)list` 转存会把
   截断排到拷贝之前 (差 4B 且后续 2B 级联)。
3. **`if (!(state&4))` 正排**: 目标 `bne` 直跳 else 的 `f_2D=state`, 子调块 sub_801D378 直落。
   写成 `if (state&4)` 则 GCC 出 `beq` 反排, 整块错位。else 是简单 store、if 含调用 → 编译器
   把含调用块放直落、简单块放跳转目标。
4. **趟2 每节点 `flag8000=0` 先于 `obj=node`**: 目标 `movs r3,#0; mov r8,r3; adds r4,r6`。
5. **循环间 `node = node->next` 双跳**: 趟1 尾 (`b _0801867C`) 与趟2 尾共用 0x801867C 的
   "advance+check" 块; C 里就是趟1 后 `node=node->next` 再 `while(key<=0xFE)` 趟2, GCC 自然合并。
6. **out/result/flag8000 三个 u8 局部 + sub sp,#4**: `out=result` 初始化经 r9(sb) 共享零常量。
