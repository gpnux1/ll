## 状态机 (gUnk_03000820)
`0 → 0x12 → 0x13 → 0x14 → 0x15 → 0x16 → 0x17 ⇄ 0x18 → 0x19 → 0x1A → 0x1B → 9`,
其中 0x1B 可回到 0x17 (位移阶段), 0x1E 收尾也回到 0x17, 最终 9。

### case 语义要点
- **case0**: 暂存 posX/posY/headA.f_1E/headA.palSlot, 计数=0, `sub_80444A4` 清同组伤害,
  `sub_803F5B4`, `sub_801CE80(obj,1,0x1B4,0xA,0)` 切动画, `f_B6=0`, `f_B4=0xF` → 0x12。
- **0x12-0x15**: 等/阈值推进 — headA.kindFlags 0x800 落 → 0x13;
  frameIdx > 0x17 → `Sfx_Play(0x66,1,1)` → 0x14;
  frameIdx > 0x47 → `Sfx_StopTrack(1)` → 0x15;
  frameIdx > 0x52 → 0x16。
- **0x16**: headA 到 0x1000 → 清位并 `|0x100`; 由 `(posX+0x2E, posY-0x2E)` 播
  `sub_8020CC4(obj, g86E, g86F, 0x27C, 0xC, 0x31A, 5)` → 0x17。
- **0x17**: headA 到 0x1000 → 清位并 `|0x100`; headB 的 0x800 未落 → 置 headB 0x100,
  计数=0 → 0x18。
- **0x18** (斜向插值到 arg1): 计数<=9 时
  `headB.frameIdx = (headB.frameIdx + 1) % 0x14`,
  `headB.f_2B = sub_801768C(g86E, arg1->posX - g86E, 0xA, 计数, 0)`,
  `headB.f_2C = sub_801768C(g86F, (arg1->posY + 4) - g86F, 0xA, 计数, 0)`, 计数++;
  到 10: `Sfx_Play(0x67,1,0)`, `headB.kindFlags &= 0xFEFF`, `frameIdx=0x14`,
  `f_2B=arg1->posX+4`, `f_2C=arg1->posY+4`, 计数=0, `sub_8044514(0x14)` → 0x19。
- **0x19**: headA 到 0x1000 → 清位并 `|0x100`; headB 到 0x1000 → `state &= 0xDFFF` → 0x1A;
  计数++。
- **0x1A**: `sub_801CE80` 复位暂存 f_1E/palSlot → 0x1B; 计数++。
- **0x1B**: headA 的 0x800 落 → 9; 计数++。
- **0x1E**: 计数<=0x1D 时 posX/posY 向 `(arg1->posX-8, arg1->posY)` 插值,
  `pad_C1 = sub_801768C(0, 0x46, 0xF, 计数, 2)`, 计数++;
  否则 `pad_C1=0`, `headA.kindFlags &= 0xFEFF`, `posY = arg1->posY + 2` → 0x17。
- **case9**: 计数++; 当 `gUnk_03000844==0 && gUnk_03000845==0 && gUnk_03000856==0` → result=1。
- **尾部**: `sub_803F658(obj); return result;`

## 关键 GCC2.9 形状
- **case26 必须 `gUnk_03000820 = 0x1B; gUnk_03000825 += 1;`**:
  目标把 case25/26/27 的 `gUnk_03000820 = <v>` store 和 `gUnk_03000825 += 1`
  跨跳合并成共享尾块 (`_0802CD90` store + `_0802CD92` 计数++)。若 case26 漏掉计数++,
  store 变成内联独立块 (+4B 实差)。
- `gUnk_0300086E/F` 是 `u8`, 参与 `arg1->posX - g86E` 等 u8 提升, `sub_801768C` 首参 s16。
- `pad_C1` (+0xC1) 直接以 `u8` 写入, 非 headA/headB 字段。
