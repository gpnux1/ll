## 语义
`sub_804ACC0`(已匹配, battle_engine.c)的富化姊妹: 在 `gUnk_0839B462` u16 表上按 `0xF00` 标记
找到第 `arg1` 个标记后的游标 `cursor`; 以 `cursor` 调 `sub_8050434(cursor, 0x4F1E)` 触发 tile DMA;
取 `TileDma_GetCtx(&local)` 得 tile 上下文数组 `gUnk_03000EE8`(经 local) 与计数 `ctxCount`。
然后遍历 `cursor[]` 直到再遇 `0xF00`:
- `entry <= 0xDF`(静态 tile id): 写两行 tilemap: `dst[0] = 0xB000 + (entry&0xFF)*2`,
  `dst[0x20] = 0xB000 + (entry&0xFF)*2 + 1`。
- `entry >= 0xE0`(动态 tile id): 在 `local[0..ctxCount-1]` 里线性查找 `entry` 得 `k`
  (找不到则 k=ctxCount), 写 `dst[0] = 0xB000 + (k+0xE0)*2`, `dst[0x20] = ... +1`。
其中 `dst = (u16*)((arg0 + 0xC6) + i*2)`, i 为遍历下标; 两行相差 0x40 字节。
- 与 ACC0 差异: 表地址同, 但 DMA 参数 0x4F1E(ACC0=0x6F1E); 有 dst 写出 + 动态查找。
