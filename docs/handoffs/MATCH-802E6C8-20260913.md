## 关键 GCC2.9 形状
- **0x18/0x1A 的共享尾块**: 源码写成
  `if (计数 <= 3) { 计数 += 1; break; } sub_804C728(...); 计数=0; state=...;`

  合并消失、字节差。
- case28 的 `(u8)(posX+4)` / `(u8)(posY-0x10)` 必须显式截断 (asm 有 `lsls/lsrs #24`)。
- `sub_804BF14` K&R 原型 (9 参, 末参 -1)。
