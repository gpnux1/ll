## 2. 功能语义

双参战斗演出状态机,与 sub_802E234 / sub_802DFDC / sub_802F480 同族,但本函数接收
第二个 BattleObj* (参1 = 目标对象),case18 用参2 的 posX/posY 播放锚点动画
`sub_8020CC4(arg, arg2->posX, arg2->posY, 0x27C, 0xE, 0x30C, 5)`。

- case 0: 记录 arg 位置/调色板到 gUnk_0300082x,`sub_801CE80(arg,5,0x1B4,0xC,0)`,
  `kindFlags |= 0x100`,`sub_803F5B4`,f_B6=2/f_B4=0,state=0x12。
- case 18: headA.kindFlags&0x800 等待 → 用**参2**位置播动画 → state=0x13。
- case 19: headB.kindFlags&0x800 等待 → Sfx_Play(0x5E) → kindFlags&=0xFEFF → state=0x14。
- case 20: headA.frameIdx>0x83 → Sfx_Play(0x58) → state=0x15。
- case 21: headA.kindFlags&0x1000 → sub_801CE80(arg,0,gUnk_03000822,gUnk_03000824,0)
  → state&=0xDFFF → state=0x16。
- case 22: headA.kindFlags&0x800 → state=9。
- case 9: 三个全局 ==0 → ret=1。
- 尾部 sub_803F658(arg) 后返回 ret。

## 3. 关键证据点

1. **双参判定**: sub_803F444 在 r4=arg0, r6=arg1 后对多个 slot 分支都用
   `adds r0,r4; adds r1,r6; bl <handler>`,确认第二参透传。本函数入口
   `adds r4, r1, #0` 且 case18 用 r4 读 posX/posY (0xBF/0xC0)。
2. **case 0 写 0x100 而非 0x800**: ROM 为 `movs r2,#0x80; lsls r2,r2,#1` (=0x100),
   起初误写 0x800 (`lsls #4`) 造成 2 字节差; 改为 0x100 后归零。
3. **返回 u32**: prologue `push {r4,r5,r6,r7,lr}` + `movs r7,#0`,ret 存活于 callee-saved r7;
   header 原声明 `void sub_802E49C()` 已改为 `u32 sub_802E49C(BattleObj *, BattleObj *)`。
