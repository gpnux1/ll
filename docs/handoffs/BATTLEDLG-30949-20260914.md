# 类型分析 handoff: 0x03000949..0x0300097D 全局簇 → gBattleDlg* (2026-09-14, agent=zcode-dlg-9xx)

## 任务
分析 linker.ld 中 0x03000949-0x0300097D 共 21 个未登记 IWRAM 全局并合理命名。

## 结论
该簇 = **战斗结算/展示渲染状态机** (battle result/presentation renderer), 由主状态机
`sub_8048FB8` (按 `gBattleIntroState` 0x03000910 分派 22 态, battle task @0x08017E00 逐帧调用,
尾部每帧调 `sub_8048F0C`) 驱动, 通过命令表向 DialogCtx BG map (0x02035AC0) 写入结算画面。

## 主状态机 sub_8048FB8 状态表 (22 态, 跳转表 E0)
0: 等 DialogCtx_GetField_C(0)==4 → 0x970=GetObjPool, state=1, 0x974/0x979=89E8 收参战, 0x97A=0;
1/2: 参战逐个登场 (sub_801CBA4(obj, palSlot, slot*60+435, 9, 0), 等 [obj+0x24]&0x800);
3/13: 0x954=94F0(state), 0x950=AB40(state-3), state=0xE; 4: 0x97D/0x97B 闪光预备;
5-11: 0x954=94F0(state) (4-11 经 sub_8049AD8 逐 stat 恢复/滚动); 12: 同 5-11 但 r0=0xC;
14: 92C0(0x956,2,1) 完成则 0x956=0x95A, state=0x14; 15/17: 92C0 完成则 0x954=94F0, state=0x14;
16: 0x954=94F0, r0=0xA; 18: 0x954=94F0, r0=0x11; 19: GetField_C(0)==0 → Disp_Bg1Off, 返回 1;
20: &0x1000 → AD54+ABD0, state=0x954; else AD24; 21: DialogCtx_SetHead(0,4,2), state=0x13。

## 渲染器 sub_80492C0 命令表 (E0, 段表 gUnk_0839B2E0 + 0x950)
格 u16 值 0x6E0-0x6E6 = opcode: 0=tile 动画(ABF8, 帧表按 80487A4(0x949) 选), 1=9958,
2=通用字形, 3=9B70(0x96C 图形段), 4=97B0 显示 0x956, 5=97B0 显示 0x9C0[0x9BF*4+1],
6=98E0; 其他值 = 字形 spec (≤0xDF: tile*2-0x5000; >0xDF: 经 0x030009CC 动态 tile 分配)。
段尾 0xFFF0 → 返回 1 (格推进/上层状态推进)。
