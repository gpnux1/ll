## 关键 GCC2.9 形状
- **帧计数共享尾块**: 所有 `break`/`continue` 都汇到尾部 `gUnk_03000825 += 1` (asm `b 0x312`
  直接跳到 `adds r0,#1`); 0x15/0x17/0x18/0x19 的 `if (计数 <= N) { ...; 计数 += 1; }` 由 GCC
  合并成共享 `_0802B078` 块 (`adds r0,#1; strb r0,[r5]; b 0x30E`), 之后仍走尾部自增。
  逐字匹配的关键是**在 case 内写显式 `gUnk_03000825 += 1;` 且在函数尾再写一次**。
- **`obj->state &= 0x2000`**: asm 为 `movs r0,#0x80; lsls r0,r0,#6; ands r0,r1; strh r0,[r2]`
  (非 `&= 0xDFFF`); 源码必须按此写。
- **REG_DISPCNT**: `*(volatile u16 *)0x04000000 &= 0xFDFF` (asm `movs r2,#0x80; lsls r2,r2,#0x13`)。
- `sub_8019B98` 返回 u8 → `== 0` 判断自动带 `lsls/lsrs #24`。
- `sub_804B96C` K&R 原型 (9 参, 末参 -1), 调色板槽取 `obj->headA.palSlot` (+0x35),
  第二参 `(u8)sub_801B954(&obj->headA)` 显式截断。
- case21/23 的 `(s16)` 实参由 `sub_801768C` 原型决定 (`0xC`/`-0xC`/`0x14` 与第4参 `gUnk_03000825`, 第5参 u8=2)。
