### 语义 (高置信)
四层循环重建 2x2 分块贴图 (tilemap "map_view"):

```
for y in 0..31:
  for x in 0..31:
    a = gP47E8[y*32 + x]                     // 块属性 (每 x 重读)
    for i in 0..1:
      for j in 0..1:
        b = gP4690[a*4 + i*2 + j]            // 源块号
        src = (u16*)gP482C + b*4             // 源 4 个 u16
        dst = (u16*)gP4620 + y*512 + x*4 + i*256 + j*2
        dst[0]=src[0]; dst[1]=src[1]; dst[128]=src[2]; dst[129]=src[3]
```

- gP47E8 = *(u32*)0x030047E8, gP4690 = *(u32*)0x03004690,
  gP482C = *(u32*)0x0300482C, gP4620 = *(u32*)0x03004620 (均为 IWRAM 指针变量)。
- 全部按 volatile 每块重读 (目标每条访问都重新 `ldr [pc]`)。

### 关键类型/形状约束
- 乘法必须以 `int` 型进入指针运算 (见 `idxMul` 助手): 直接 `(int)(y*32)` 会被前端 fold 回 u32，
  代码生成不同。

## 3. 剩余差异 (唯一)

3 个 halfword，全部属于 0x03004620 基址载入：

| 偏移 | 目标 | 本候选 |
|---|---|---|
| 0x58 | `ldr r3,[pc]` | `ldr r0,[pc]` |
| 0x5a | `ldr r2,[r3]` | `ldr r3,[r0]` |
| 0x5e | `adds r3,r0,r2` | `adds r3,r3,r0` |

即目标把"地址/值/结果"分到 r3/r2/r3 三个角色 (3 操作数 add)，
本候选把"基址值"与 dst 合并 (2 操作数 add)。

### 根因 (RTL 级确认, 用 `agbcc -da` 导出)
前端把 `dst = *p; dst += off;` 归一化为：
```
insn143: reg58 = 0x03004620
insn145: reg37 = mem[reg58]      ; dst 变量直接承载基址值
insn205: reg37 = reg37 + reg75   ; dst = dst + off  → 2 操作数
```
目标要求 `regDst = reg75 + regVal` 且 regDst ≠ regVal (基址值必须是独立伪寄存器)。
GCC2 前端/lcoal-alloc 总是把二者合并；`-fno-regmove` 无效。
