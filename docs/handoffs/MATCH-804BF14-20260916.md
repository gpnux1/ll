## 2. 机器契约与语义建模
本函数是**BG 调色板**淡变动画的启动器 (opcode 3, 逐帧由 `sub_804B4D0` 消费驱动), 与已匹配的
OBJ 版本 `sub_804B96C` 构成同构姊妹对。为动画槽范围 `[arg0, arg0 + arg1)` 初始化调色板条目
`PaletteAnimEntry`。

### 2.1 依赖关系与生命周期
- **上游调用者**: BG 调色板演出状态机 (与 OBJ 版同样的换装/形态切换流程, 使用 BG 槽位)。
- **被调子函数**:
  - `sub_804C5B8(u8 slot, u8 count)`: BG 调色板槽占用标记 (置位 `gBgPalSlotUsed` bit)。
  - `sub_804C638(u8 slot)`: 将 BG 硬件调色板 (`0x05000000 + slot * 32`) 经 DMA3 备份至影子内存。

### 2.2 全局变量与结构体
- `gBgPalAnim` (`0x03000BE8`): `PaletteAnimEntry` 16 项条目数组 (每项 16 字节, BG 调色板动画表)。
- `gBgPalSlotUsed` (`0x03000AE2`): 16 槽占用位图 (bit0..15)。

> ⚠ 命名说明: 2026-09-14 全仓已纠正旧标签互换 —— 本函数操作的是 BG 调色板 (`0x05000000`),
> 即 `gBgPalAnim`/`gBgPalSlotUsed`; OBJ 版 `sub_804B96C` 才用 `gObjPalAnim`/`gObjPalSlotUsed`。

### 2.3 参数与语义
- `arg0` (`u8`): 起始动画条目槽位 (`gBgPalAnim` 索引)。
- `arg1` (`u8`): 槽位数量 (`count`)。
- `arg2` (`s8`): 红色分量增量 `dR` (钳位 <= 0x1F)。
- `arg3` (`s8`): 绿色分量增量 `dG` (钳位 <= 0x1F)。
- `arg4` (`s8`): 蓝色分量增量 `dB` (钳位 <= 0x1F)。
- `arg5` (`u8`): 淡变动画周期 `period`。
- `arg6` (`u8`): 往返方向/帧步长 `dir` (若在 (0, period) 范围内则使用, 否则赋为 `period`)。
- `arg7` (`s8`): 优先扫描的首选调色板槽 (若 < 0 则从 0 起搜寻)。
- `arg8` (`u8`): 模式选择 (2: 固定槽号 `arg0 + i`, 3: 扫描 `gBgPalSlotUsed` 分配首个可用空闲槽)。
- **返回值**: 首个动画条目的 BG 调色板槽号 `(s8)gBgPalAnim[arg0].palSlot`。

## 3. 匹配方法 (复用姊妹)
对 `asm/matchings/sub_804B96C.s` 与 `asm/nonmatchings/sub_804BF14.s` 做归一化 (地址/标签/字面池)
逐指令 diff: **两者指令流完全相同**, 差异仅为:
- 字面池常量: `0x03000AE8`→`0x03000BE8` (OBJ→BG 表), `0x03000AE0`→`0x03000AE2` (OBJ→BG 位图);
- `bl` 目标: `sub_804C364`→`sub_804C5B8`, `sub_804C3E4`→`sub_804C638`。

因此直接把 `sub_804B96C` 的已匹配 C 体按上述映射改写为 BG 系统即完全命中。**姊妹同构验证是同族
函数最优路径**: 先证明指令同构, 再机械映射全局/被调, 无需重新搜索 GCC2.9 形状。

### 3.1 破局关键 (与 sub_804B96C 一致, 对 BG 版同样必须)
1. **数组字段直接访问**: 必须写为 `gBgPalAnim[arg0 + i].field`, 不引入局部指针 `PaletteAnimEntry *entry`
   (可维持寄存器分配与 `sub sp, #0x20` 栈帧尺寸)。
2. **空闲槽起始索引初始化分支**:
   ```c
   if (arg7 >= 0)
       b = arg7;
   else
       b = 0;
   ```
   若写成三元表达式或先赋 0 再条件覆盖, GCC2.9 会引入额外临时寄存器导致 `adds r4, r0, #0` 差异;
   if-else 精准生成 `movs r4, #0` 与条件跳转。
3. **首槽偏移预计算与返回值复用**: 主循环前 `slot = arg0 * 16;`, 令 GCC 把 `arg0 * 16` 缓存在栈上
   `[sp, #0x18]`, 循环后直接经该栈槽读取首项 `palSlot` 并符号扩展返回。
