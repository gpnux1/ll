## 3. 关键形状点

1. **switch 上界**: 必须显式写空 `case 25: case 26: case 27: break;`, 使 GCC 生成 `cmp #0x1b`
   与 28 项跳转表 (0..27)。只写当前有效 case 会让上界=0x18, `cmp #0x18`, 整函数少 12 字节
   (实测 632→644, 差分 36→30)。
2. **计数递增位置**: 只有 `case 0x18` 与 `case 9` 的等待分支递增 `gUnk_03000825`;
   其余状态转移 (含 case 0) 直接 `break` 跳过递增。源码写成这两个 case 内显式 `+= 1`, 其余自然 break 即可。
3. 字段偏移由同 module 已匹配函数交叉确认: headB 基址 +0x3C, kindFlags=headB+0x18=+0x54,
