## 4. GCC2.9 形状要点（本次匹配的关键，勿随意改）

1. **外层必须是"提前判定 + 尾部收尾"，且不能写 `return` 早退或 `goto`**：

   ```c
   if (obj->slot <= 0xA) { switch (...) {...} return; }
   if (obj->slot <= 0x70) sub_804CEE0(obj, pool);
   else                   sub_804DD70((u8 *)obj, (u32)pool);
   ```

   - 写成 `if (slot > 0xA) { ...; return; } switch(...)`：`slot > 0xA` 块被排到函数前部，fndiff **3025**。
   - 写成 `if (slot > 0xA) goto special; ... special:`：块序正确，但多出一个分支形态，且 `goto` 属禁用手段。
   - 最终写法与目标布局一致：开头 `cmp #0xa / bls <switch> / b <0x1a2>`（CEE0/DD70 块落到函数尾），`switch` 的 default 落到 `return`。

2. **`case 3` 的扫描循环必须留在 `if (pool[f_BD].slot <= 0xA) { ... }` 块内**。把它挪到 `if/else` 之后（虽然语义等价、也在原 ASM 里同样只出现一次），GCC 会把该循环甩到函数最尾部并翻转 `cmp #5` 的分支极性，fndiff **2990**。

3. `case 0` / `case 3` 内部的 `if (obj->variantClass == 5) {...} rand(...)` 与取反写法（`!= 5` 再 else）**等价**：16 种组合全部 fndiff 0，字节完全一致。

4. `(u8)(vc - 7) > 1` 与 `vc != 7 && vc != 8` **等价**（两者都 fndiff 0）；最终源码用手写比较式。

5. `switch ((u8)sub_801F76C(obj))` 与 `switch (sub_801F76C(obj))` 等价 —— `lsls #0x18/lsrs #0x18` 是本工具链对 **u8 返回值**的调用点再截断（`sub_801D468` 里对 `sub_80489E8` 同样出现），不是源码里的显式 cast 造成。
