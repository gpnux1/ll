- 全部消费者为 INCLUDE_ASM (menu.c: sub_801417C/80146A8/8014A68/8015658/InvUi_Main),

- InvUi_Main 的成对存储 (strb 229 + str 22C) 与 progress.md:5233 的 codex-menu 笔记直配。
