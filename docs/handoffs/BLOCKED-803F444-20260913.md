## 关键 GCC2.9 形状 (已确认, 使 0x16c vs 0x170 仅差 4B)
- 外层 `slot` 用 if/else 链 (`cmp #0xA; bhi` → `subs #0xB; cmp #0x65; bhi` → `cmp #0x70`)。
- fxKind 必须写成 **switch (s8)** 且只列 case 0/1: 生成 `cmp #0; beq A; cmp #1; beq B; b tail`
  (if/else 会把 case0 内联, 布局不同)。
- skill 分支必须 **读两次 `obj->pad_A1`** (`if (pad_A1<=7) v=skills[pad_A1]; else v=pad_A1;`),
  GCC2.9 不做跨分支 CSE, 才产生目标的 `ldrb r0,[r1]` + `ldrb r1,[r1]` 双读与 `bhi` 极性。
- slot>0x70 分支的 fxKind 判断必须写成 `if (k==0) ; else if (k==1) v=...;`
  (生成 `cmp #0; beq skip; cmp #1; bne skip` 双比较)。
- 无末尾 `return`: 目标 epilogue `_0803F5A8` 不改 r0, 且无 `movs r0,#0` 默认。

## 唯一残差 (卡点)
**CD5C 分派分支的 animPtr 临时寄存器**: 目标 `ldr r2,[obj+0x88]` (r2=slot 已死被复用),
候选 `ldr r1,[obj+0x88]`。派生差异:
- k==1 时目标 `animPtr+0x30` 以 r2 为基址, 候选以 r1 为基址;
- 目标尾部 `_0803F5A8` 在 0x164, 候选在 0x162 (2B 布局偏移), 导致 4 个 `b` 目标字节差。
