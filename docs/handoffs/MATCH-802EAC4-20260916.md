## 寄存器与未初始化局部变量 (ROM 真 UB) 说明
1. 在 case 30 中，`sub_801CE80(obj, 0, gObjActSavedF2A, palSlot, 0)` 的第 4 参数生成了 `adds r3, r4, #0`。
2. 在原 ROM 中，`r4` 是 callee-saved 寄存器，在 case 30 执行之前未被任何指令写入（唯一的写入点在 case 23 的 `ldrh r4, [r0]`）。
3. 这与 `sub_802E6C8`/`sub_802EDD8`/`sub_802F100` 对比极其明确：
   - 姊妹函数在 case 0 保存了 `gObjActSavedPal = obj->headA.palSlot;`，并在 case 30 传入 `gObjActSavedPal`。
   - 本函数原作者在 case 0 遗漏了保存 `palSlot`，在声明了局部变量 `u8 palSlot;` 后在 case 30 直接传入。
   - GCC 2.9 (agbcc) 将未初始化局部变量分配给第一个空闲 callee-saved 寄存器 `r4`，生成 `adds r3, r4, #0`。
   - 这与项目中已确认的 ROM 真 UB 模式完全吻合（详见 `EXPERIENCE.md` 经验 155 及 `MATCH-801FF40` 等案例）。
