## 3. 精确剩余差异 — 仅 2 字节

`permuter/sub_802A154/base.c` 经 bytecmp (忽略 bl 槽) 只剩 **2 字节**:

```
offsets 0x4f9, 0x67f
target: adds r2, #1     ; r2 = 表基址 (0x0839DF90)
cand:   adds r0, #1     ; r0 = 下标 (gUnk_030008A5*2)
```

即 case30 (_0802A5EC else) 与 case36 (_0802A79C) 里
`gUnk_0839DF90[gUnk_030008A5*2 + 1]` 的 index 计算:
- ROM 把 `+1` 加在**表基址**上 (`adds r2,#1; adds r0,r0,r2`), 于是基址→r2、下标→r0;
- 候选把 `+1` 加在**下标**上 (`adds r0,#1; adds r0,r0,r2`), 基址→r0、下标→r2。

指令数/形状/立即数全对, 纯 local-alloc 寄存器 home 互换 + 该寄存器名占 1 字节。

## 4. 已排除实验 (全部仍 2 字节, 或更差)

- `*(base + (idx+1))` / `*(base + 1 + idx)` 指针算术: 仍 r0/r2 互换 (case36 反而 4B 变化)。
- `u8 *p=&base[idx]` / `u8 *tbl=base` 局部: 变差 (1400+/485/41 diffs)。
- `u16 idx` / `s16 idx` 局部: 变差 (17/15 diffs), 或把值挤进 callee-saved。
- `(base)[]` 加括号 / `2*idx` 交换 / `idx|1` / `(void)0`: 仍 2。
- 强转字面量 `((u8*)0x0839DF90)[]` (经验 102 写法): case30 形状对但 load 顺序仍差
  (16 diffs, 多出池字), case36 更差。
- 语句顺序 (A2AC/kindFlags 前后调换): 无效。
