## 2. 机器契约与语义建模
该函数是战斗动画子系统的 OBJ 调色板淡变动画启动器 (fade animation, opcode 3, 逐帧由 `sub_804B4D0` 消费驱动)。为动画槽范围 `[arg0, arg0 + arg1)` 初始化调色板条目 `PaletteAnimEntry`。

### 2.1 依赖关系与生命周期
- **上游调用者**:
  - `src/event_actor.c`: 换装/形态切换演出状态机 (5 处调用, 包括 `sub_802A154`、`sub_802F6D8` 等)。
  - `src/battle_engine.c`: 闪光对话框对象调色板淡变 (`gBattleDlgFlashPal` 槽位)。
- **被调子函数**:
  - `sub_804C364(u8 slot, u8 count)`: 调色板槽占用标记 (置位 `gObjPalSlotUsed` bit)。
  - `sub_804C3E4(u8 slot)`: 将硬件调色板 (`0x05000200 + slot * 32`) 经 DMA3 备份至影子内存 (`0x02036AC0 + slot * 32`)。

### 2.2 全局变量与结构体
- `gObjPalAnim` (`0x03000AE8`): `PaletteAnimEntry` 16 项条目数组 (每项 16 字节)。
- `gObjPalSlotUsed` (`0x03000AE0`): 16 槽占用位图 (bit0..15)。

### 2.3 参数与语义
- `arg0` (`u8`): 起始动画条目槽位 (`gObjPalAnim` 索引)。
- `arg1` (`u8`): 槽位数量 (`count`)。
- `arg2` (`s8`): 红色分量增量 `dR` (钳位 <= 0x1F)。
- `arg3` (`s8`): 绿色分量增量 `dG` (钳位 <= 0x1F)。
- `arg4` (`s8`): 蓝色分量增量 `dB` (钳位 <= 0x1F)。
- `arg5` (`u8`): 淡变动画周期 `period`。
- `arg6` (`u8`): 往返方向/帧步长 `dir` (若在 (0, period) 范围内则使用, 否则赋为 `period`)。
- `arg7` (`s8`): 优先扫描的首选调色板槽 (若 < 0 则从 0 起搜寻)。
- `arg8` (`u8`): 模式选择 (2: 固定槽号 `arg0 + i`, 3: 扫描 `gObjPalSlotUsed` 分配首个可用空闲槽)。
- **返回值**: 首个动画条目的硬件调色板槽号 `(s8)gObjPalAnim[arg0].palSlot`。

## 3. 破局关键与 GCC 2.9 特征
1. **数组字段直接访问**: 与姊妹函数 `sub_804B654` 完全一致，表项访问必须写为 `gObjPalAnim[arg0 + i].field`，不能引入局部指针 `PaletteAnimEntry *entry`，以维持寄存器分配和栈帧尺寸 (`sub sp, #0x20`)。
2. **空闲槽起始索引初始化分支**:
   ```c
   if (arg7 >= 0)
       b = arg7;
   else
       b = 0;
   ```
   若写为三元表达式 `b = (arg7 < 0) ? 0 : arg7;` 或先赋 0 再条件覆盖，GCC 2.9 会引入额外的临时寄存器导致 `adds r4, r0, #0`，而 if-else 则精准生成 `movs r4, #0` 与条件跳转，达到 100% 字节一致。
3. **首槽偏移预计算与返回值复用**:
   在进入主循环前执行 `slot = arg0 * 16;`，使 GCC 将 `arg0 * 16` 缓存在栈上 `[sp, #0x18]`，循环结束后直接通过该栈槽读取首项 `palSlot` 并符号扩展返回。
